🚀 Розгортання на сервері (VPS / домашній ПК)

Варіант 1 — Docker Compose (найпростіше)

git clone <ваш-репозиторій> tg-relay-console
cd tg-relay-console
docker compose up -d
docker compose logs -f

Займає порт 3000 (змініть в docker-compose.yml, якщо він зайнятий).

Варіант 2 — systemd (звичайний запуск на Ubuntu/Debian)

# 1. Встановіть Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 2. Скопіюйте проєкт на сервер, наприклад у /opt
sudo mv tg-relay-console /opt/
cd /opt/tg-relay-console
npm install --omit=dev

# 3. Автозапуск сервісу
sudo cp deploy/tg-relay.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tg-relay
sudo journalctl -u tg-relay -f

Відкриваємо порт для інтернету

# ufw (Ubuntu firewall)
sudo ufw allow 3000/tcp

# На VPS — переконайтесь, що порт відкритий у панелі хостера (Security Group).
# На домашньому ПК — прокиньте порт 3000 на роутері (Port Forwarding) на адресу ПК.

Адреса доступу: http://ВАШ_SERVER_IP:3000

Бонус: безкоштовний HTTPS (рекомендовано)

# Виставлений домен + Caddy:
sudo apt-get install -y caddy  # або завантажте з caddyserver.com
echo 'tg.example.com {
    reverse_proxy localhost:3000
}' | sudo tee /etc/caddy/Caddyfile
sudo systemctl reload caddy

Caddy сам отримає сертифікат Let's Encrypt. Потім заходьте за https://tg.example.com.
